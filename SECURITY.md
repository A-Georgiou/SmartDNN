# Security Policy

## Supported Versions

The latest code on the `main` branch is currently the only supported version of SmartDNN.

| Version | Supported |
| ------- | --------- |
| `main`  | ✅ |
| older releases and branches | ❌ |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately and do not open a public GitHub issue.

Send reports to [AndrewGeorgiou98@outlook.com](mailto:AndrewGeorgiou98@outlook.com) and include:

- a clear summary of the issue
- affected files, components, or commit hashes
- reproduction steps or a proof of concept, if available
- the potential impact

The maintainer will review the report, acknowledge receipt, and follow up with remediation details when appropriate.
