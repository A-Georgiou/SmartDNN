# Security Policy

## Supported Versions

Security updates are currently provided for the latest code available in the default branch of this repository.

| Version | Supported |
| ------- | --------- |
| Latest commit on `main` | :white_check_mark: |
| Older commits or forks | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in SmartDNN, please report it privately by email to [AndrewGeorgiou98@outlook.com](mailto:AndrewGeorgiou98@outlook.com).

When reporting an issue, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version, commit, or branch
- Any proof-of-concept, logs, or screenshots that help explain the issue
- Your preferred contact details for follow-up

Please do **not** open a public GitHub issue for security vulnerabilities.

## What to Expect

After a report is received, the maintainer will review the issue, confirm the impact, and work on a fix as appropriate. Reports will be handled as confidentially as possible until a remediation or disclosure plan is ready.

## Disclosure

Please allow time for investigation and remediation before publicly disclosing a vulnerability.
